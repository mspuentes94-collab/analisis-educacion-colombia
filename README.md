# Proyecto de Análisis de Educación en Colombia

Este proyecto realiza un análisis exploratorio y visualización de datos educativos en Colombia, utilizando **Python**, **pandas** y **matplotlib**.  
El dataset incluye información sobre **deserción**, **cobertura neta** y **aprobación** por departamento y año.

---

## 📂 Estructura del proyecto
- `analisis.py` → Script principal con todo el flujo de análisis.
- `Datos/EDUCACION.csv` → Archivo de datos en formato CSV (separador `;`).
- Gráficas generadas → Se muestran en pantalla al ejecutar el script.

---
